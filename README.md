# Recipe Finder
A simple web-based tool where you can find recipes you can make.
## Installation
```
git clone https://github.com/AadiCharpe/recipe_finder.git
cd recipe_finder
cd backend
```
## Setup
```
pip install "fastapi[standard]"
fastapi dev main.py
```
Finally, run the frontend on a live server. 
Now you can add the ingredients you have and find the recipes you can make. 
Each recipe will have an image, ingredient list, and step-by-step instructions.
